# Phase 2 Report: Public Data Fixtures

## Objective

Create a deterministic public market-data fixture for the fixed-rate bond example and keep live downloads out of C# tests, examples, and CI.

## Selected Source

Phase 2 uses the Federal Reserve nominal yield curve CSV at:

```text
https://www.federalreserve.gov/data/yield-curve-tables/feds200628.csv
```

The source page describes the data as fitted nominal yield-curve parameters and smoothed yields from 1961 to present. The CSV itself states that this is a staff research product, not an official statistical release.

The fixture uses `SVENYXX` fields because the CSV header defines them as continuously compounded zero-coupon yields. Treasury par yields and New York Fed SOFR data remain useful later sources, but they are not used for the first direct-zero curve fixture.

## Fixture Contract

Pinned fixture:

```text
examples/FixedRateBondSurrogate/Data/fed-nominal-yield-curve-2026-05-15.json
```

The JSON records:

- source institution and URLs;
- download date and curve date;
- source limitations;
- original Fed field names;
- units: percent;
- compounding: continuous;
- day count used by the harness: Actual/365;
- interpolation convention: linear in zero rates;
- selected maturities: 1Y, 2Y, 3Y, 5Y, 7Y, 10Y, 20Y, 30Y.

The C# adapter converts percent yields to decimal zero rates. It adds a valuation-date anchor using the 1Y zero yield so QLNet receives a curve whose first pillar is the valuation date.

## Implementation

- Optional refresh tool: `tools/RefreshFixedRateBondMarketData/refresh_fed_nominal_yield_curve.py`.
- C# fixture records and loader: `examples/FixedRateBondSurrogate/MarketData.cs`.
- Runtime example: `examples/FixedRateBondSurrogate/Program.cs`.
- Tests: `tests/ChebyshevSharp.Tests/Finance/FixedRateBondReferencePricerTests.cs`.

The refresh tool uses only Python standard-library modules. It downloads the Fed CSV, finds the actual `Date,...` header row after the source metadata rows, selects a pinned curve date, and writes normalized JSON.

## Limitations

This fixture is a direct zero-rate curve for tutorial reproducibility. It is not a bootstrapped market-quote curve and does not include the quote-level "trickle-down" behavior used by production curve-risk systems. Later phases should keep zero-pillar DV01 clearly separate from market-quote DV01.
