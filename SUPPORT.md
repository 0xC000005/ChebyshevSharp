# Support

ChebyshevSharp support works best when reports are small, reproducible, and
explicit about the numerical expectation.

## Questions

Use GitHub Discussions for usage questions:

https://github.com/0xC000005/ChebyshevSharp/discussions

Include the class you are using, a minimal code sample, the domain, node counts,
and the result you expected.

## Bugs

Use the bug report template:

https://github.com/0xC000005/ChebyshevSharp/issues/new/choose

Include the ChebyshevSharp version, .NET SDK/runtime version, operating system,
minimal reproduction, expected behavior, and actual behavior.

## Numerical Accuracy

Use the numerical accuracy template for approximation, derivative, integral,
root, optimization, Tensor Train, or sensitivity-analysis concerns. Include the
function, domain, construction settings, observed value, expected value, and an
independent reference calculation.

## Security

Do not open public issues for security vulnerabilities. Follow the security
policy:

https://github.com/0xC000005/ChebyshevSharp/security/policy
